## What I like

**Noise → signal.** Most of what looks like a result isn't one — a benchmark that
measures something other than what it claims, a correlation standing in for a cause,
a metric quietly drifting from the thing it was supposed to stand for. The part I
enjoy is finding the one measurement that tells those apart.

It's the through-line in what I've published:

| | |
| --- | --- |
| [**AgentSuite**](https://openreview.net/pdf?id=2Exmr1eIKZ) · ICML 2026 | Audits LLM-agent benchmarks for validity flaws. The defects are real enough to reorder model rankings — so the benchmark was the noise. |
| [**Causal Brain Connectivity**](https://link.springer.com/chapter/10.1007/978-3-031-95841-0_81) · AIME 2025 | Recovers *directional* dependencies that correlation graphs are blind to, across ~8,000 patients. |
| [**Brain Network State Transformer**](https://www.cs.emory.edu/~jyang71/files/bnst.pdf) · IEEE EMBC 2025, oral | Models transitions between latent connectivity states instead of averaging them away. |

## What I want to build

Systems increasingly run without a human at every step, so oversight has to move from
human attention to **instrumented monitorability** — if you can't watch it, it has to
report on itself.

The constraint I find interesting: attention is rationed, not removed. Whoever is
watching can only afford a handful of escalations, so a monitor is only worth anything
at a **low false-positive rate**. Average-case accuracy is the easy part; being right
when you interrupt someone is the real one.
